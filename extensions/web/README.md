# InkUp extension

The browser extension: Chrome, Firefox and Safari from one WXT codebase. Build and load it as the
[root README](../../README.md) describes. It is released on its own train, `inkup-extension-v<version>`, which
uploads to the Chrome Web Store and addons.mozilla.org ([docs/releasing.md](../../docs/releasing.md)). release-please
keeps this package's `version` and `CHANGELOG.md`.
