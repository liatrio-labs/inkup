# InkUp extension

The browser extension: Chrome, Firefox and Safari from one WXT codebase. Build and load it as the
[root README](../../README.md) describes. Every release tags it `inkup-extension-v<version>`, with the same version
as the host's `inkup-v<version>`, and uploads it to the Chrome Web Store and addons.mozilla.org; a release candidate
stays on GitHub ([docs/releasing.md](../../docs/releasing.md)). release-please keeps this package's `version` and
`CHANGELOG.md`.
